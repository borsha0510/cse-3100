Rick & Morty Explorer
1.Summary of Implemented Features-

 Browse characters from the Rick and Morty API with pagination.
 Search characters by name.
 Filter characters by status (Alive, Dead, Unknown).
 Responsive and clean UI with navigation.
 Contact form with validation.
 Dark mode support for better viewing experience.
 About page with app info and developer details.

2.Additional Improvements-
 Added smooth loading states for API requests.
 Improved form validation with user-friendly error messages.
 Styled components with consistent design and accessibility in mind.
 Used React Router for SPA navigation.

3.Setup and Run Instructions-

 Clone the repository:
 git clone https://github.com/borsha0510/rick-morty-explorer.git
 Navigate to the project folder:
 cd rick-morty-explorer
 Install dependencies:
 npm install
 Start the development server:
 npm start
 Open your browser and go to http://localhost:3000 to see the app.

4.Known Issues or Limitations-

 Pagination only shows 10 characters per page.
 No backend support for contact form submissions (only frontend validation).
 API rate limits may occasionally affect fetching data.
 Dark mode toggle is not implemented; dark mode relies on CSS class switching.
